## Code. Music. Live.

Trevosonic Pie is a *new kind of musical instrument*—a fork of Sonic Pi enhanced with
pattern-based live coding features inspired by uzulang/strudel. Instead of strumming
strings or whacking things with sticks, you write code—**live**.

Trevosonic Pie has been designed with the aim to find a harmonious balance
between four core principles:

* **Simple** enough for the 10 year old within you
* **Joyful** enough for you to lose yourself through play
* **Powerful** enough for your own expressions
* **Pattern-driven** for terse, expressive musical sequences

Trevosonic Pie is a complete open source programming environment originally
forked from Sonic Pi to explore *pattern-based composition* and *teach programming
concepts* through the process of creating *new sounds*.

In addition to being an engaging education resource it has evolved into
an *extremely powerful* and performance-ready *live coding instrument* suitable
for professional artists and DJs.

Whilst education is a core focus, it now sits at the intersection
between three core domains:

* **Art** - providing the means to express yourself and ask new questions of music and notation
* **Technology** - exploring questions related to liveness, time, concurrency, and pattern-based composition in programming languages
* **Education** - demonstrating that open play rather than rigid structures increases motivation and engagement in the classroom

Again, finding a balance working to the best benefits of all these
domains is the objective.


* Upstream: https://sonic-pi.net (original Sonic Pi project)
* Inspiration: https://github.com/tidalcycles/strudel (pattern-based live coding)
* Source: https://github.com/davidjberube/trevosonic-pie

## About This Fork

Trevosonic Pie builds upon the excellent foundation of Sonic Pi by Sam Aaron and contributors,
integrating pattern-based live coding concepts from uzulang/strudel and other modern live coding
environments. This fork aims to provide a more streamlined workflow for pattern-based composition
while maintaining all the power and expressiveness of the original Sonic Pi.

## Pattern Notation

Trevosonic Pie introduces pattern notation inspired by strudel/TidalCycles for concise musical sequences:

```ruby
# Traditional approach
live_loop :melody do
  play :c4
  sleep 0.25
  play :e4
  sleep 0.25
  play :g4
  sleep 0.25
  play :b4
  sleep 0.25
end

# Pattern notation (planned for v0.2.0+)
# pattern(:melody, "c4 e4 g4 b4")
```

Features planned:
* Mini-notation for sequences and rhythms
* Euclidean rhythm support
* Pattern transformations (reverse, rotate, speed)
* Probabilistic patterns
* Polyphonic/chord notation

See [PATTERNS.md](PATTERNS.md) for complete documentation and examples.
